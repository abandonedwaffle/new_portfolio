About Me

System dossier // active

I'm a self-taught developer from India, building real products while working through The Odin Project curriculum. I don't wait until I'm ready — I ship things, break them, audit them, and make them better.

My approach is systems-first. Before writing a line of code, I think about data models, user flows, and what the core software interface is actually trying to solve. The visual presentation always emerges from function, not decoration.

I'm drawn to projects with a strong editorial identity — software that has a clear point of view and commits to it completely.

Core Directives & Principles

01. Ship SHIP REAL THINGS — Side projects that go live teach more than a thousand tutorials.
02. Models DATA ARCHITECTURE FIRST — Design the data model before the interface. Structure outlasts style.
03. Audits SELF-AUDIT CODE — Trust but verify. Always run checks against your own assumptions.
04. Design FUNCTIONAL DESIGN — Aesthetic is not decoration. It is the product's interface argument.
05. Intelligence AI AS HANDS, NOT BRAIN — Use tools to build faster, but the logic design must remain human.
06. Shipped FINISH THE MISSION — The gap between 90% and shipped is where quality is decided.
